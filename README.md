# Портфолио

Сайт-портфолио: все демо из папки «Фриланс» на одной странице. Статический HTML, без сборщика, можно выкладывать на Vercel как есть (папка `site/`).

## Идея

**«Сайты, у которых есть своя идея».** Главный аргумент: ни одно демо не похоже на другое. Поэтому:

- каждый проект показан своей главой **в своих цветах и своим шрифтом заголовка**, а шапка сайта перекрашивается под проект, который сейчас на экране;
- у каждого проекта есть **ролик всего сайта** (от первого экрана до подвала, до 30 с) в рамке браузера с полоской прогресса и мобильная версия в рамке телефона;
- три ветклиники (Доктор Вет, Sas, Пульс) — отдельные главы: одна ниша, три разных сайта;
- рамка портфолио в сиреневой гамме; блок «Кроме сайтов» — контекстная реклама и продвижение аккаунтов (пока без кейсов);
- список «Все работы» с фильтром по нише, чтобы владелец бизнеса сразу нашёл свою;
- 32dent.by вынесен в первый экран: это единственный сайт, который уже работает у клиента.

## Как посмотреть

```
python3 -m http.server 4210 --bind 127.0.0.1 --directory site
```
Открыть http://127.0.0.1:4210

## Как добавить или поправить проект

1. Тексты, цвета, ссылки: `src/data.mjs`. Статусы: `live` (работает у клиента), `online` (демо выложено), `local` (ссылки нет), `wip` (в работе).
2. Скриншоты и ролик: адрес демо в `capture/capture.mjs` (SITES), затем
   - `cd capture && node capture.mjs <id>` — скриншоты;
   - `node full.mjs <id>` — ролик всего сайта: клики фишки на первом экране (PRELUDE), остановки по пути (STOPS), плавная прокрутка до подвала; адрес в URLS;
   - `node process.mjs <id>` — обрезка, ускорение, сжатие в `site/media/`.
3. `node src/build.mjs` — пересобирает `site/index.html`.

Важно: Next.js-проекты в dev-режиме снимать через `localhost`, а не `127.0.0.1`, иначе скрипты страницы не запускаются и анимации стоят.

## Где что лежит

- `site/` — готовый сайт (index.html, styles.css, main.js, media/)
- `src/` — данные и сборщик страницы
- `capture/` — съёмка и обработка роликов; `capture/raw/` — исходники, в репозиторий не нужны
